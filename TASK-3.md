# Задание 3. Форма регистрации

## Что вы сделаете

Соберёте форму регистрации на Frontend Open Day и постепенно улучшите её средствами самого HTML.

В конце задания форма должна:

- отправлять данные методом GET;
- показывать значения в адресной строке;
- группировать связанные варианты;
- использовать нативную проверку браузера;
- демонстрировать разницу между `readonly` и `disabled`.

## С чего начать

1. Откройте `starter/index.html` в редакторе и браузере.
2. Рассмотрите готовое поле «Имя и фамилия».
3. Сначала выполните **этап 1** и обязательно отправьте форму.
4. Только после этого переходите к этапам 2 и 3.

Для сравнения есть два изображения:

- `preview/checkpoint-basic.png` — форма после первого этапа;
- `preview/expected-result.png` — итоговая форма.

## Этап 1. Соберите работающую форму

### 1. Электронная почта

Создайте `label` и `input`:

```html
name="email" type="email"
```

Значения `for` и `id` должны совпадать.

### 2. Телефон

Добавьте поле:

```html
name="phone" type="tel"
```

Добавьте пример номера в `placeholder`.

### 3. Курс обучения

Добавьте `select` с `name="study_year"` и вариантами:

| Текст         | value           |
| ------------- | --------------- |
| Выберите курс | пустое значение |
| Первый        | `1`             |
| Второй        | `2`             |
| Третий        | `3`             |
| Четвёртый     | `4`             |
| Другое        | `other`         |

### 4. Согласие

Добавьте checkbox:

```html
name="rules" type="checkbox" value="accepted"
```

Используйте уже готовые БЭМ-классы блока `choice` из CSS.

### 5. Отправка

Добавьте кнопку:

```html
type="submit" class="button button--accent registration-form__submit"
```

Заполните форму и отправьте её.

Браузер должен открыть `result.html`, а в URL должны появиться параметры примерно такого вида:

```text
?full_name=Анна+Смирнова&email=student%40example.com&study_year=2
```

**Не переходите дальше, пока не понимаете, откуда в URL взялись имена и значения параметров.**

## Этап 2. Добавьте ограничения и подсказки браузеру

Вернитесь к той же форме и улучшите уже созданные поля.

### Имя

Добавьте:

```html
required autocomplete="name" minlength="2" maxlength="80"
```

### Email

Добавьте:

```html
required autocomplete="email"
```

### Телефон

Добавьте:

```html
autocomplete="tel"
```

Телефон остаётся необязательным.

### Курс

Сделайте `select` обязательным.

Первый пустой `option` должен быть:

```html
selected disabled
```

### `readonly` и `disabled`

Добавьте два текстовых поля:

1. **Мероприятие** — `name="event"`, значение `Frontend Open Day 2026`, атрибут `readonly`.
2. **Стоимость** — `name="price"`, значение `Бесплатно`, атрибут `disabled`.

Позже сравните URL после отправки.

## Этап 3. Добавьте группы выбора

### Формат участия

Создайте `fieldset` с `legend` «Формат участия».

Внутри должны быть два radio:

| Текст  | value     |
| ------ | --------- |
| Очно   | `offline` |
| Онлайн | `online`  |

У обоих:

```html
name="participation"
```

Один вариант должен быть выбран по умолчанию. Группа обязательна.

### Интересующие темы

Создайте второй `fieldset` с `legend` и тремя checkbox:

| Текст                | value        |
| -------------------- | ------------ |
| HTML и CSS           | `html-css`   |
| JavaScript и браузер | `js-browser` |
| Vue                  | `vue`        |

У всех используйте:

```html
name="topics"
```

Здесь пользователь может выбрать несколько вариантов.

### Вопрос спикерам

Добавьте `textarea`:

```html
name="question" maxlength="300"
```

### Согласие

Checkbox из первого этапа сделайте обязательным через `required`.

## Проверьте форму

Перед сдачей выполните несколько экспериментов.

1. Попробуйте отправить пустую форму.
2. Введите неправильный email.
3. Введите имя из одного символа.
4. Не отмечайте обязательное согласие.
5. Выберите две темы и отправьте форму.
6. Сравните параметры `event` и `price` в URL.

Обратите внимание: значение `readonly`-поля должно попасть в данные, а `disabled`-поля — нет.
